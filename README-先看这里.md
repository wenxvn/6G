## 先记住的时间和规则

- 报名及作品提交截止：**2026-11-13 20:00**。
- 学生组最多3人，须为同一学校（不含分校）；可单人参赛。企业组最多5人；队长年龄及团队平均年龄不超过45岁。最多可填2名指导教师/专家。
- 作品材料须按要求匿名：作品方案、演示视频和答辩PPT等不得出现团队单位名称、LOGO或指导教师/专家信息。
- 方案需转成PDF且不超过15 MB；演示视频为MP4，3–5分钟且不超过300 MB；答辩PPT也须以PDF提交。
- 作品名称不超过20字；简介300–500字；佐证材料合并为一个PDF。若提交大容量代码/图纸等材料，按通知要求放入百度网盘并提交永久有效分享链接。
- 需保证原创、数据和案例真实；引用第三方技术、算法或数据时标明来源并取得合法授权。使用生成式AI撰写时，须如实说明使用情况并对内容负责。

## 赛题方向

- **创新产品**：AI与6G融合的软硬件产品或系统，重点看技术创新、落地可行性和应用前景。
- **创业项目**：围绕6G产业链，呈现AI+6G技术、商业模式、落地价值和产业化前景。
- **场景设计**：围绕真实业务需求提出可落地的AI+6G场景方案，可提交已实施方案或设计方案。

## 下一步

1. 先选定赛题类别和学生组/企业组，再使用对应模板。
2. 按评分标准准备技术/市场证据、应用验证和佐证材料，并检查匿名要求。
3. 关注队长邮箱和短信；截止后报名团队成员及指导教师信息不能修改。
